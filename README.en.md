# Gustavo Ben Abraham — Portfolio

[Português](README.md) | **English**

I am Gustavo Ben Abraham, an aspiring back-end developer focusing on Java, Spring Boot and PostgreSQL. This portfolio presents my learning journey, projects and technologies.

[Visit the portfolio](https://gustavobenabraham.github.io/portifolio/)

## About

A personal website built with native HTML, CSS and JavaScript, without a framework or build step. It presents my background, selected projects, technologies, interests and contact information. Although the site itself is a frontend project, my professional focus is back-end development.

## Features

- Responsive desktop, tablet and mobile layout.
- Accessible mobile menu with keyboard navigation, Escape support and closing on link selection.
- Header appearance changes on scroll.
- Canvas character animation in the hero section.
- Section entrance animations and reduced-motion support.
- Semantic HTML, accessible labels, search metadata and Open Graph tags.

## Technologies and concepts practiced

HTML5 for structure, CSS3 for layout/responsiveness, JavaScript for DOM interactions and Canvas, Google Fonts for Inter/JetBrains Mono, and GitHub Pages for hosting.

The project provides practice with semantic markup, keyboard interaction, responsive layouts, browser animation and static-site publishing.

## Run locally

No dependencies or compilation step are required:

```bash
git clone https://github.com/GustavoBenAbraham/portifolio.git
cd portifolio
```

Open `index.html` in a browser or serve the folder using VS Code Live Server.

## Structure

```text
index.html             # Page structure and content
style.css              # Theme, layout and animations
script.js              # Interactions
```

## Publishing

The site is hosted on GitHub Pages. Publish changes to the branch configured under Settings → Pages; there is no application build step. See [technical documentation](docs/DOCUMENTACAO.md) for maintenance details.
